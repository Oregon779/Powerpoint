Anleitung

So läuft's auf dem Fernseher

1Verbinden

iPad und Fernseher im selben WLAN. Kontrollzentrum → Bildschirmsynchronisierung.

2Starten

iPad quer halten, Präsentation antippen. Sie passt sich automatisch an.

3Vorführen

Rechts tippen = weiter, links = zurück. Zum Beenden 2× in die Ecke oben links tippen.

★Profi-Tipp

Safari → Teilen → Zum Home-Bildschirm. Dann ohne Browser-Leisten.
